# S7 地址速查（s7.md）

> **来源**：docs/189 §2（地址格式）+ §21.1（边界规则），基于 `S7AddressData.ParseFrom` 的地址格式事实。
> **进制**：10 进制 / 10 进制（189 §18）；**字节序**：大端（ABCD，西门子默认）。
> ⚠️ 写任何 S7 地址前：对照下方四节，**边界地址必须跑通再进点表**。

## 三、边界规则（§21.1，源码依据核对）

| 边界项 | 规则 |
|--------|------|
| V 区隐含 DB | `V*` 强制 `DbBlock=1`、`DataCode=132`（V100 = DB1.DBB100） |
| T/C 仅字访问 | `T`/`C` 不支持位寻址（`isCT=true` 时偏移不乘 8） |
| 地址 0 有效 | `M0`/`DB1.DBB0` 均合法（S7 无"地址不能为 0"限制） |
| 位偏移上限 | 未显式限制（由 PLC 实际容量决定） |
| SM/AI/AQ/PQ 型号 | **仅 S7-200/300 存在**；1200/1500 通常没有 → 配置这些区会失败 |

## 四、陷阱（常见错 = 现场事故）

| 症状 | 原因 | 自查 |
|------|------|------|
| `T0.0`/`C0.0` 位操作失败 | T/C **仅字**（定时器/计数器当前值） | 改用字访问 |
| 读 `V100` 结果对不上 | V 区隐含 **DB1**（不是别的 DB） | 确认对象是 DB1 |
| 位写没效果/覆盖相邻位 | 位地址格式错（第 3 段才是位号）+ 未走读-改-写 | `DB1.DBX0.2` 三段式；位写必读-改-写 |
| 值永远是"倒的" | S7 **大端**（ABCD），按小端解析会错 | 字节序配置 ABCD |
| 字符串多 2 字节/乱码 | String 头 = [MaxLen, ActualLen]（如 `[254,3,'A','B','C']`） | `StringKind=S7String`（§docs/83） |
| 1200/1500 上读 SM/AI/AQ 失败 | 这些区仅 200/300 有 | 型号不同换地址 |

## 五、典型示例

```
读 M100          → M100         （标志位，字：MW100）
读 DB1 第 1 个字  → DB1.DBW0     （或 DB1.DBD0 双字）
读 DB1 位 0.2    → DB1.DBX0.2
读隐含 DB1 的字  → VW20         （= DB1.DBW20）
读定时器当前值   → T0           （仅字，无位）
```

## 六、对照与验证

- 边界核对：`docs/189` §2（格式）与 §21.1（边界）；实现对照 `S7AddressData.ParseFrom`。
- 验证：用 `PlcSimulatorFixture` 读回比对（**能连上 ≠ 地址对，值必须对**）；S7 位写路径必须过"读-改-写"单测。
