# Mitsubishi MC 地址速查（mc.md）

> **来源**：docs/189 §4（地址格式）+ §21.3（边界规则），基于 `McAddressData.ParseMelsecFrom` 的地址格式事实。
> **进制**：位区多 16 进制、字区 10 进制（189 §18）；**X/Y/DX/DY 以 0 开头按 8 进制**（本协议第一大陷阱）。
> ⚠️ 写任何 MC 地址前：对照下方四节，**边界地址（8↔16 进制/临界值）必须跑通再进点表**。

## 〇、端序与批量路径（2026-09-29 使用验证实测补充）

- **线序 = 小端（Little-Endian）**；自研 `MitsubishiMcDriver` 内部（`BitConverter`）与 HSL（`RegularByteTransform`）一致。
- ⚠️ 2.2.12 的 `EndianConverter` 声明曾误为 BigEndian → typed 写/批量读值错乱（写 1234 读回 0xD204）；
  2.2.13 已修正为 LittleEndian（docs/213）——**若用 2.2.12 且值错位，先升 2.2.13**。
- ⚠️ **批量位区限制（已知缺口，docs/213 遗留#3）**：采集引擎把位区标签（M/X/Y/L…）按字块读，
  **实测 M96/M97（16 对齐）批量也不出值** —— MC 位区在批量引擎下**不可用**（非对齐问题，是引擎按字模型处理位区）；
  位区请走驱动直读（`ReadBool`）路径或改用 D/R/ZR/W 字区；真实 PLC 协议层支持位访问，缺口在引擎批量模型。

## 三、兼容格式与 iQ-R（§4.3–4.5）

| 系列 | 要点 |
|------|------|
| **Keyence** | `MR10`/`LR10`/`CR10` = **16 进制位压缩**（high×16+low，如 `R101`=0x65×…）；`R` 位访问映射为 `Keyence_Y`；`EM`→`D` 且地址 +100000；`ZR10F` 按十进制 |
| **Panasonic** | `R≥14400` → 特殊继电器 SM（地址 −14400）；`D≥90000` → SD（地址 −90000）；`DT` 等同 D |
| **iQ-R U 模块** | `U0\D100`=模块0 数据寄存器、`U1\M100.3`=模块1 位、`U0\X20` / `U0\W10` … |

## 四、边界规则（§21.3，源码依据核对）

| 边界项 | 规则 |
|--------|------|
| X/Y/DX/DY 进制 | 以 `0` 开头按 **8 进制**，否则按 16 进制（`X010`=8、`X10`=16） |
| S* 子类型 | 仅 `SN/SS/SC/SM/SD/SB/SW` 合法（S 裸字符 = 步进） |
| C* 子类型 | 仅 `CN/CS/CC/CR/CM` 合法，**其他 C\* 抛异常**（无裸 C） |
| T* 子类型 | 仅 `TN/TS/TC` 合法，**其他 T\* 抛异常**（无裸 T） |
| Keyence 位压缩 | `MR/LR/CR`：`CalculateComplexAddress` 用 `high*16+low` |
| Keyence R 位 | `isBit=true` 时 `R*` 映射为 `Keyence_Y` |
| Keyence E/ZR | `EM`→`D`+100000；`ZR10F` 十进制 |
| Panasonic 分界 | `R≥14400`→SM（−14400）；`D≥90000`→SD（−90000） |

## 五、陷阱（常见错 = 现场事故）

| 症状 | 原因 | 自查 |
|------|------|------|
| `X010` 和 `X10` 值不同 | **0 开头=8 进制**（X010=字节 8、X10=16） | 位/字区都查进制 |
| `B100` 按 M 的 10 进制理解 | B 区是 **16 进制**（M 是 10 进制） | 进制定位到"区域" |
| 写 `C10`/`T10` 报错 | C*/T* **无裸字符**（须 CN/CS/CC/TN/TS/TC） | 补子类型 |
| Keyence `R101` 按 101 理解 | R 是 **16 进制位压缩**（high×16+low） | 对照 §4.3 |
| Panasonic `R15000`/`D95000` 读错 | **跨临界换区**（R≥14400→SM、D≥90000→SD） | 临界两侧都要测 |

## 六、典型示例

```
读 X 位 0x10      → X10        （16 进制位 16）
读 X 位 8         → X010       （0 开头 = 8）
读 M 位 80        → M80        （十进制位 80）
读 D 字 100       → D100       （十进制字）
读链接寄存器字    → W100       （16 进制字）
读定时器当前值    → TN10       （字）
读 iQ-R 模块 0    → U0\D100
```

## 七、对照与验证

- 边界核对：`docs/189` §4（格式）与 §21.3（边界）；实现对照 `McAddressData.ParseMelsecFrom`。
- 验证：**8↔16 进制切换、C/T 子类型白名单、Keyence/Panasonic 兼容格式** 必须单测覆盖（边界地址优先，189 要求）；用 `PlcSimulatorFixture` 读回比对（值必须对）。
