# Allen-Bradley 地址速查（ab.md）

> **来源**：17 协议地址格式规范 §6（地址格式）+ §21.5（边界规则），基于 `AllenBradleySLCAddress` 解析类的地址格式事实。
> ⚠️ **冒号必填**（`N7:0`，缺冒号直接报错）；位访问 `N7:0/5` 或 `N7:0.5`（位号 0–31）。

## 一、区域速查（§6）

| 区域 | 格式示例 | DataCode | DbBlock | 说明 |
|------|----------|----------|---------|------|
| A（模拟量输出） | `A9:0` | 142 | 9 | |
| B（位存储） | `B3:1` | 133 | 3 | |
| N（整数） | `N7:0` | 137 | 7 | |
| F（浮点） | `F8:0` | 138 | 8 | |
| ST（字符串） | `ST9:0` | 141 | 9 | 双字符前缀 |
| S（计时器/计数器） | `S2:0` | 132 | **2（默认）** | |
| C（计数器） | `C5:0` | 135 | 5 | |
| I（输入） | `I:0` | 131 | **1（默认）** | |
| O（输出） | `O:0` | 130 | **0（默认）** | |
| R（控制） | `R6:0` | 136 | 6 | |
| T（计时器） | `T4:0` | 134 | 4 | |
| L（长整数） | `L10:0` | 145 | 10 | |

**位访问**：`N7:0/5` 或 `N7:0.5`（位号 0–31，协议层限制）。

## 二、边界规则（§21.5，源码依据核对）

| 边界项 | 规则 |
|--------|------|
| **冒号必填** | 地址必须含 `:`，否则报错 `"Address can't find ':'"` |
| S 默认块 | `S` 单独出现 → DbBlock=2 |
| I 默认块 | `I` 单独出现 → DbBlock=1 |
| O 默认块 | `O` 单独出现 → DbBlock=0 |
| ST 双字符 | `ST` = DataCode 141，DbBlock 取 `Substring(2)` |
| 位访问 | 位号 0–31（`N7:0/5` 或 `N7:0.5`） |

## 三、陷阱（常见错 = 现场事故）

| 症状 | 原因 | 自查 |
|------|------|------|
| 报错 `can't find ':'` | **冒号必填**（写 `N7 0` 而非 `N7:0`） | 补冒号 |
| ST 字符串读错 | ST 双字符前缀（141 + `Substring(2)`）；**字符串头长度元数据按规范解析**（cross-test 曾修 LEN 偏移） | ST9:0 + StringKind 规范 |
| `I:0` 读的区不对 | I 默认 DbBlock=1（I 单字符语义） | 默认块规则 |
| 位读没取到 | 位语法 `N7:0/5`（位号 0–31） | 位号范围 |

## 四、典型示例

```
读整数字     → N7:0
读整数位     → N7:0/5   （或 N7:0.5）
读浮点       → F8:0
读字符串     → ST9:0
读输入字     → I:0       （默认块 1）
```

## 五、对照与验证

- 边界核对：17 协议地址格式规范 §6（格式）+ §21.5（边界）；实现对照 `AllenBradleySLCAddress`。
- 验证：**冒号、ST 双字符、位号 0–31** 三条必测；字符串头长度元数据按 cross-test 实证（曾修 LEN 偏移）；用仿真器读回比对（值必须对）。
