# Fatek 地址速查（fatek.md）

> **来源**：17 协议地址格式规范 §7（地址格式）+ §21.6（边界规则），基于 `FatekProgramAddress` 解析类的地址格式事实。
> ⚠️ **字节序 = CDAB**（国产典型，**非**西门子 ABCD）——交叉验证实测确认（2026-09 字节序修正），写值/读回对不上先查字节序。

## 一、区域速查（§7，十进制 ASCII）

| 区域 | 格式示例 | DataCode | 说明 |
|------|----------|----------|------|
| X（输入） | `X100` | X | 位，十进制 |
| Y（输出） | `Y100` | Y | 位，十进制 |
| M（辅助继电器） | `M100` | M | 位，十进制 |
| S（步进继电器） | `S100` | S | 位，十进制 |
| T（定时器） | `T100` | T | 位，十进制 |
| C（计数器） | `C100` | C | 位，十进制 |
| D（数据寄存器） | `D100` | D | 字，十进制 |
| R（文件寄存器） | `R100` | R | 字，十进制 |
| RT（累计定时器） | `RT100` | RT | 位（R+C 子类型） |
| RC（累计计数器） | `RC100` | RC | 位（R+C 子类型） |

**字符串化规则**（§21.6）：X/Y/M/S/T/C 用 D4（4 位）；D/R/RT/RC 用 D5（5 位）。

## 二、边界规则（§21.6，源码依据核对）

| 边界项 | 规则 |
|--------|------|
| RT/RC 子类型 | `RT` = `R`+`T`、`RC` = `R`+`C`，各自独立 DataCode（**不能裸写 R 代替**） |
| 字符串化填充 | X/Y/M/S/T/C 用 D4；D/R/RT/RC 用 D5 |
| 大小写 | 支持（`x100` / `X100` 均合法） |
| 地址上限 | `Convert.ToUInt16` → 最大 **65535**，越界报错 |
| **字节序** | **CDAB**（交叉验证实测；读回"顺序颠倒"先查字节序） |

## 三、陷阱（常见错 = 现场事故）

| 症状 | 原因 | 自查 |
|------|------|------|
| 读回值"字节顺序颠倒" | **字节序 CDAB**（Fatek 与西门子 ABCD 不同） | 字节序配置 CDAB |
| 想写累计定时器却按普通 T 写 | RT/RC 是独立子类型（R+C） | 用 `RT100`/`RC100` |
| 地址 > 65535 报错 | `Convert.ToUInt16` 上限 | 分区域/换类型 |
| `RT100` 与 `R100` 混读 | 子类型 DataCode 不同 | 按 RT/RC 写 |

## 四、典型示例

```
读输入位       → X100
读数据寄存器   → D100     （字，字节序 CDAB）
读文件寄存器   → R100     （字）
读累计定时器   → RT100    （子类型 RT）
读计数器       → C100     （位）
```

## 五、对照与验证

- 边界核对：17 协议地址格式规范 §7（格式）+ §21.6（边界）；实现对照 `FatekProgramAddress`。
- 验证：**字节序 CDAB、RT/RC 子类型、65535 上限** 三条必测（Fatek 单元测试已进门禁，2026-09 交叉验证）；用仿真器读回比对（值必须对）。
