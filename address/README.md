# 地址速查（address/）— 17 协议一眼定位 + 防地址灾难

> **来源**：docs/189（基于协议地址解析类逐条审阅，17 类 * 边界规则）；本目录是 Skill 的"地址硬约束"模块。
> ⚠️ **铁律（docs/212 M2）**：**地址格式必须先对照本速查核对，禁止凭记忆写**；边界地址（进制切换/临界值/位字切换）**必须跑通（单测或仿真）后才算数**。

## 一、四维检查法（写任何地址前，过一遍）

| 维度 | 问什么 | 典型（189 依据） |
|------|--------|------------------|
| **进制** | 这个区域按几进制？ | MC X/Y/DX/DY 以 0 开头=**8 进制**（§21.3）；ToyoPuc **全 16 进制**（§21.12）；XinJE/FxLinks X/Y=8 进制（§21.16/21.19）；Yokogawa 全十进制（§21.9） |
| **临界值** | 越过临界会不会换区域/换码？ | Vigor M/D≥9000→SM/SD、C≥200（§21.11）；Panasonic R≥14400、D≥90000（§21.3）；XinJE 临界（SM4096/HD6144/FD8192…）（§21.16）；EB 分段 PRG9/10/11（§21.12） |
| **位寻址模式** | 位怎么写？字.位？独立位区？压缩？ | S7 `DBX0.0` 字节.位；Omron `CIO100.03` = 字*16+bit（§5）；AB `N7:0/5`（§21.5）；Keyence `R101` = high*16+low **压缩**（§9）；LSis U/I/Q **多层位公式**（§21.17） |
| **仅字/仅位** | 该区能位访问吗？ | S7 T/C **仅字**（§2.3）；GE AI/AQ/R 不支持位（§21.7）；Vigor X/Y/M/S/SM/TS/TC/CS/CC **仅位**、SD/D/R/T/C **仅字**（§21.11）；AB ST 双字符（§21.5） |

## 二、17 协议浓缩速查（常用格式 | ⚠️ 关键注意）

| 协议 | 常用地址示例 | ⚠️ 关键注意 |
|------|-------------|-------------|
| **S7** | `M100` `I0.0` `Q0.0` `DB1.DBX0.0` `V0` `T0` `C0` | T/C 仅字；V 隐含 DB1；SM/AI/AQ/PQ 仅 200/300 系列；地址 0 合法 |
| **Modbus** | `100` `64H` `s=2;x=3;100` | **40001 式解析未实现**（不认 4X/HR 前缀）；`H` 后缀=16 进制；位靠功能码 |
| **MC** | `X10` `Y1A` `M80` `D100` `W100` `TN10` | X/Y/DX/DY 以 0 开头=8 进制；S*/C*/T* 子类型白名单（写错抛异常）；iQ-R 用 `U0\D100` |
| **Omron** | `CIO100` `CIO100.03` `DM100` `EM0.10` | 字*16+bit；CV 与非 CV 偏移不同（DR/AR/TIM/CNT）；EM 银行号 16 进制；D=DM/C=CIO/W=WR/H=HR/A=AR 别名 |
| **AB** | `A9:0` `B3:1` `N7:0` `N7:0/5` `ST9:0` | **冒号必填**；S/I/O 默认块 2/1/0；位号 0-31；ST 双字符=141 |
| **Fatek** | `X100` `D100` `RT100` `RC100` | RT/RC=R+C 子类型；X/Y/M/S/T/C 用 D4、D/R 用 D5 填充；上限 65535 |
| **GE** | `AI100` `R100` `I100` | **地址 0 非法（自动报错）**；解析后自动减 1；AI/AQ/R 不支持位 |
| **Keyence** | `R10.1` `MR10` `DM100` `CTH10` | R/CR/MR/LR **16 进制位压缩**（high*16+low）；VB/W 16 进制；SplitLength 固定（CTH=2/CTC=4/Z=12/其余 256/64） |
| **Yokogawa** | `X100` `CN100` `TN100` | 全十进制；CN/TN 双字符前缀；无点号位寻址 |
| **Memobus** | `100` `100.3` `mfc=32;x=3;100` | MFC 默认 32、SFC 字 3/位 1；`100.3` = 100*16+3 |
| **Vigor** | `X10` `M10` `D10` `C200` | **M≥9000→SM(148)、D≥9000→SD(161)、C≥200→173**；位/字严格分离 |
| **ToyoPuc** | `K100` `D100` `EK100` `GX100` | **全十六进制**；E* 强制 PRG0；EB<32768→PRG9/…≥65536→PRG11；K/V/T/C/L/X/Y/M 可位写 |
| **Fuji SPB** | `X10` `D10` `W10` | TypeCode 固定 2 位 16 进制；T/C 仅 TN/TC/CN/CC |
| **Fuji SPH** | `I10` `M1.10.2` | 仅 M1/M3/M10 模块号；位 `M{模块}.{地址}.{位}` 三字段 |
| **Fuji Cmd** | `TS100` `W9.100` `WL100` | **仅大写**（小写报错）；W 段白名单 9/21~26/30~109/120~123/125 |
| **XinJE** | `X10` `M100` `D100` `HD100` | X/Y **8 进制**；临界地址（SM4096/HD6144/FD8192 等，用于协议版本切换） |
| **LSis** | `P100` `D100` `U100.0.0.0` | 首字符白名单（P/M/L/K/F/T/C/D/S/Q/I/N/U/Z/R）；U 位 `hex*32+bit`、I/Q 3 段公式；B=1/W=2/D=4/L=8 倍率 |
| **Fanuc** | `G100` `F100` `D100` | 仅 G/F/Y/X/A/R/T/K/C/D/E 11 区；地址 0 合法 |
| **FxLinks** | `X10` `D100` `TS100` `TN100` | X/Y **8 进制**；T/C 仅 TS/TN/CS/CN；填充 4/5/6/7 位（≥10000 加 2 位） |

## 三、常见"地址错误 = 现场事故"症状

| 症状 | 大概率地址原因 | 自查 |
|------|----------------|------|
| 读回永远错位/错值 | 偏移按 10 进制写、实际 16 进制（MC X/Y、ToyoPuc） | 过"进制"维 |
| 某些地址能写、相邻的不能写 | 越过临界值没换区域（Vigor 9000/200、Panasonic 14400/90000） | 过"临界"维 |
| 位写没反应/覆盖相邻位 | 位寻址模式写错（把位区当字节、或没走读-改-写） | 过"位寻址"维 + 读-改-写 |
| 整块读取失败、影响其他标签 | 坏地址混进合并块 → 触发隔离 | 单点探测确认坏地址后修点表 |

## 四、验证方法（写地址后必做）

1. 每个地址在 `address/` 速查里核对过（含边界四维）；
2. **边界用例优先跑**：8↔16 进制切换、临界值两侧（9000 前后）、位/字切换、0 地址——不跑不算数；
3. 用 `PlcSimulatorFixture` 或真实驱动**读回比对**（能读写成功 ≠ 地址对，必须值对）；
4. 新增协议/新格式 → 先补本目录速查（标注"以厂商最新文档为准 + 对照源码验证"），再进点表。
