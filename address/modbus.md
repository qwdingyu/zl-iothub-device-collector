# Modbus 地址速查（modbus.md）

> **来源**：docs/189 §3（地址格式）+ §21.2（边界规则），基于 `ModbusAddress.Parse` 的地址格式事实。
> ⚠️ **本协议第一大坑**：HSL 的 Modbus 地址解析**不识别行业常见的 `40001 / 4X / HR` 写法**——纯数字就是**字节偏移**（§3.5/§21.2，源码依据 `ParseAddressHelper`）。

## 一、地址形式（§3）

### 1.1 行业习惯写法（⚠️ HSL 解析**不实现**，仅在与其他栈互通时参考）

| 写法 | 等效 | 区域 | 功能码 |
|------|------|------|--------|
| `40001` | — | HR（保持寄存器） | 0x03 读 / 0x06 写 |
| `30001` | — | IR（输入寄存器） | 0x04 |
| `00001` | — | C（线圈） | 0x01 读 / 0x05 写 |
| `10001` | — | DI（离散输入） | 0x02 |
| `4X0010` / `HR100` | `40010` | HR | 同上 |
| `3X0010` / `IR100` | `30010` | IR | 0x04 |
| `1X0001` / `DI100` | `10001` | DI | 0x02 |
| `0X0001` / `COIL100` | `00001` | C | 0x01/0x05 |

### 1.2 HSL 实际支持的形式（§3.4）

| 形式 | 示例 | 含义 |
|------|------|------|
| 纯数字 | `100` | 直接字节偏移 |
| 十六进制 | `0X64` | 0x64 = 100 |
| H 后缀 | `64H` | 16 进制，= 100 |
| 富地址 | `s=2;x=3;100` | 站号 2、**读**功能码 3、地址 100 |
| 富地址写 | `s=2;w=6;100` | 站号 2、**写**功能码 6、地址 100 |

## 二、边界规则（§21.2，源码依据核对）

| 边界项 | 规则 |
|--------|------|
| **40001 式解析** | **未实现**：`ModbusAddress.Parse` 只解析纯数字/富地址，不识别 `4X`/`HR` 等前缀；写 `40001` = 偏移 40001（不是"寄存器 1"） |
| 十六进制后缀 | 地址以 `H` 结尾按 16 进制（`64H` → 100） |
| 站号默认 | 未指定 `s=` 时 `Station = -1`（是否下发由调用方决定） |
| 功能码默认 | 未指定 `x=` 时 `Function = -1` |
| 写功能码 | `w=` 仅影响写操作，不影响读功能码 |
| 地址 0 | 合法（`0` → 0） |
| 位访问 | Modbus 无统一位寻址：线圈/离散输入靠**独立功能码**（1/2/5/15），不是"普通地址 + .bit" |

## 三、陷阱（常见错 = 现场事故）

| 症状 | 原因 | 自查 |
|------|------|------|
| 按 `40001` 写、读到的不是"寄存器 1" | `40001` 被当**偏移 40001**（行业语义 ≠ HSL 语义） | 用富地址 `s=;x=;addr` 或直接偏移 |
| 读写总不生效 | 未指定 `s=`（Station=-1，站号未下发） | 富地址带站号 |
| 线圈/离散输入解析失败 | 位 = 独立功能码（1/2/5/15），不支持"地址 .bit" | 换线圈/离散输入语义 |
| `0X64` 当成 64 | `0X` 前缀 = 16 进制（0x64 = 100） | 区分进制 |

## 四、典型示例

```
读保持寄存器（站 1）   → s=1;x=3;100      （x=3 读保持寄存器）
写保持寄存器（站 1）   → s=1;w=6;100      （w=6 写保持寄存器）
读线圈（站 1）         → s=1;x=1;0X01     （x=1 读线圈）
十六进制地址           → 64H / 0X64       （= 偏移 100）
直接字节偏移           → 100
```

## 五、对照与验证

- 边界核对：`docs/189` §3（格式）+ §21.2（边界）；实现对照 `ModbusAddress.Parse`。
- 验证：**`40001` 式 / `0X` 前缀 / 富地址 `s=;x=`** 三个形式各测一条；站号/功能码缺省行为单测（RST/Modbus RTU 用 PlcSimulatorFixture 读回比对，值必须对）。
