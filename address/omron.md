# Omron FINS 地址速查（omron.md）

> **来源**：docs/189 §5（地址格式）+ §21.4（边界规则），基于 `OmronFinsAddress.ParseFrom` 的地址格式事实。
> ⚠️ 两大坑：**位 = 字×16 + 位号**（`CIO100.03` = bit **1603**）；**CV 与 非 CV 型号的操作码/偏移不同**（DR/AR/TIM/CNT），选错型号值就读错。

## 一、区域速查（§5，位操作码 / 字操作码）

| 区域 | 格式 | 位码 | 字码 | 说明 |
|------|------|------|------|------|
| CIO | `CIO100` / `CIO100.03` | 48 | 176 | I/O 通道；`C` = CIO 别名 |
| W | `W100` / `W100.15` | 49 | 177 | 工作区 |
| H | `H100` / `H100.7` | 50 | 178 | 保持继电器 |
| A | `A100` / `A100.0` | 51 | 179 | 辅助继电器（`AR` 别名） |
| DM | `DM100` / `DM100.5` | 2 | 130 | 数据存储器（`D` = DM 别名） |
| EM | `EM100` / `EM0.10` | 32~47 / 224~239 | 160~175 / 96~111 | 扩展内存（银行号 16 进制） |
| E | `E100` / `E0.10` | 10 | 152 | 同 EM |
| IR | `IR100` | — | 220 | 索引寄存器（仅字） |
| DR | `DR100` | — | 188 | 数据寄存器（CV 型） |
| TIM | `TIM100` / `TIM100.0` | 9 | 137 | 定时器 |
| CNT | `CNT100` / `CNT100.0` | 9 | 137 | 计数器 |
| CF | `CF100` | 7 | — | 状态标志（仅位） |

## 二、位计算与别名（§5）

```text
位值：CIO100.03 → 100 × 16 + 3 = 1603
别名：D = DM | C = CIO | W = WR | H = HR | A = AR
```

## 三、边界规则（§21.4 + §5，源码依据核对）

| 边界项 | 规则 |
|--------|------|
| **CV/非 CV 差异** | CV 型：DR 偏移 +48、AR +45056、TIM/CNT 规则另定；非 CV：DR 偏移 **+8192**、CNT +524288——**同一地址在 CV/非 CV 机上语义不同** |
| EM 银行号 | `EM0.10` 中银行号按 **16 进制**：<16 → 位 32~47 / 字 160~175；≥16 → 位 224~239 / 字 96~111 |
| 别名区 | D=DM、C=CIO、W=WR、H=HR、A=AR（同一区，不另占偏移） |
| IR 偏移 | IR 固定偏移 **+4096** |
| TIM/CNT | 位、字均可访（位码 9 / 字码 137） |

## 四、陷阱（常见错 = 现场事故）

| 症状 | 原因 | 自查 |
|------|------|------|
| `CIO100.03` 按 103 理解 | 位 = **字×16 + 位号**（=1603） | 位换算（×16） |
| CV 机上 DR/TIM/CNT 值错 | CV/非 CV 偏移不同 | `OmronPlcType` 型号选对 |
| `EM100` 与 `EM0.100` 混淆 | 银行号 16 进制 + 双操作码范围 | 按 §三 EM 规则 |
| 用 `D100` "换区"读不到 | D **=** DM（别名不是另一区） | 别名表 |
| 位写没反应 | 位访问要用**位操作码**（不是字码） | TIM100.0 等按位码 |

## 五、典型示例

```
读 CIO 字    → CIO100        （字码 176）
读 CIO 位    → CIO100.03     （= bit 1603，位码 48）
读 DM 字     → DM100         或 D100（别名）
读 EM 银行 0 → EM0.10
读定时器    → TIM100（字）／ TIM100.0（位）
DR（CV）    → DR100
状态标志    → CF100（仅位）
```

## 六、对照与验证

- 边界核对：`docs/189` §5（格式）+ §21.4（边界）；实现对照 `OmronFinsAddress.ParseFrom`。
- 验证：**位换算（×16）、CV/非 CV 偏移、EM 银行号 16 进制** 三条边界必测；用 PlcSimulatorFixture 读回比对（值必须对）。
