# GE SRTP 地址速查（ge.md）

> **来源**：17 协议地址格式规范 §8（地址格式）+ §21.7（边界规则），基于 `GeSRTPAddress` 解析类的地址格式事实。
> ⚠️ **地址从 1 开始**（`0` 非法，解析后自动减 1）；**AI/AQ/R 不支持位访问**。

## 一、区域速查（§8）

| 区域 | 格式示例 | DataCode（字） | DataCode（位） | 说明 |
|------|----------|---------------|---------------|------|
| AI（模拟量输入） | `AI100` | 10 | —（不支持位） | |
| AQ（模拟量输出） | `AQ100` | 12 | —（不支持位） | |
| R（控制寄存器） | `R100` | 8 | —（不支持位） | |
| SA | `SA100` | 24 | 78 | |
| SB | `SB100` | 26 | 80 | |
| SC | `SC100` | 28 | 82 | |
| I（输入） | `I100` | 16 | 70 | |
| Q（输出） | `Q100` | 18 | 72 | |
| M（内部） | `M100` | 22 | 76 | |
| T（定时器） | `T100` | 20 | 74 | |
| S（步进） | `S100` | 30 | 84 | |
| G（通用） | `G100` | 56 | 86 | |

## 二、边界规则（§21.7，源码依据核对）

| 边界项 | 规则 |
|--------|------|
| **地址 0 非法** | `AddressStart == 0` 报错 `"GeSRTPAddressCannotBeZero"` |
| **自动减 1** | 解析后 `AddressStart > 0` 自动减 1（用户写 100，内部 99） |
| 位操作限制 | `AI/AQ/R` 不支持位（`isBit=true` 报错） |
| 子串规则 | 单字符区（I/Q/M/T/S/G）用 `Substring(1)`；双字符区（AI/AQ/SA/SB/SC）用 `Substring(2)` |
| 大小写 | 支持（`ai100` / `AI100` 均合法） |

## 三、陷阱（常见错 = 现场事故）

| 症状 | 原因 | 自查 |
|------|------|------|
| `0` 地址报错 | **地址 0 非法**（从 1 开始） | 从 1 起 |
| AI/AQ/R 位操作失败 | 该三区**不支持位** | 用字访问 |
| 读值偏移 1 | 解析后**自动减 1**（用户 100 → 内部 99） | 地址语义从 1 开始 |
| `I100` 与 `AI100` 混 | 单/双字符区子串规则不同 | 子串规则 |

## 四、典型示例

```
读模拟量输入   → AI100    （字；不支持位）
读控制寄存器   → R100     （字）
读输入字       → I100     （或 I100.0 位，位码 70）
读通用寄存器   → G100
```

## 五、对照与验证

- 边界核对：17 协议地址格式规范 §8（格式）+ §21.7（边界）；实现对照 `GeSRTPAddress`。
- 验证：**地址 0 报错、自动减 1、AI/AQ/R 位限制** 三条必测；用仿真器读回比对（值必须对）。
